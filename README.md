### Featured project · Creative Drawing App

An interactive drawing and teaching-aid prototype developed by a student team, informed by feedback from teachers at Wenzhou Special Education School.

- **My contribution:** co-developed the application and its technical implementation.
- **Creative interaction:** themed scenes, guided drawing, tracing, voice instructions, and local artwork saving.
- **Classroom tools:** teacher-planned activities, step-by-step guidance, and local activity reports.
- **Engineering:** browser storage, automated regression checks, and an optional Node.js story-generation backend.

**Built with:** JavaScript · HTML Canvas · CSS · Tailwind CSS · Node.js
